# 💰 Mone — личный финансовый помощник

> Telegram-бот для контроля расходов с голосовым вводом на русском языке

---

## Что это

**Mone** — это умный Telegram-бот, который помогает отслеживать твои расходы. Просто говоришь ему голосом (или пишешь текстом) что и сколько потратил — он всё записывает, категоризирует и показывает статистику.

Никаких таблиц, никаких сложных приложений. Просто мессенджер, который ты и так открываешь каждый день.

---

## Как пользоваться

### Добавить расход

Отправь голосовое сообщение или напиши текстом:

```
Кофе 25 тысяч
Такси 30к
Обед 80000 сум
Кофе 25к и такси 30к
```

Бот распознает речь, разберёт сумму и категорию, покажет карточку подтверждения. Ты нажимаешь **✅ Верно** — и готово.

### Посмотреть статистику

Используй кнопки внизу экрана или команды:

| Кнопка / Команда | Что показывает |
|---|---|
| 📋 **Расходы за сегодня** | Каждая трата за день + итог |
| 📊 **Расходы за неделю** | Сколько потрачено каждый день (с графиком) |
| `/help` | Справка |

## Импорт истории из CSV

В личном чате отправь `/import`, затем загрузи CSV **документом**. Бот сохраняет
исходный текст CSV и показывает период, суммы доходов/расходов, категории и первые
пять операций. Записи появляются в учёте только после нажатия «Импортировать».
Подтверждение принадлежит отправителю, хранится в PostgreSQL и действует 24 часа,
в том числе после перезапуска бота.

Готовый пример: [examples/import.csv](examples/import.csv).

```csv
date,type,amount,currency,category,description
2026-10-01,income,5000000,UZS,,Oylik
2026-10-02,expense,25000,UZS,,Kofe
```

- Обязательны `date` и `amount`; вместо `amount` допустимы отдельные `income` и
  `expense` (только один положительный столбец на строку).
- Распознаются русские и узбекские заголовки: `дата` / `sana`, `сумма` / `summa`,
  `тип` / `turi`, `категория` / `kategoriya`, `описание` / `izoh`, `валюта` / `valyuta`,
  `kirim` / `chiqim`.
- `type`: `income` / `expense`, `доход` / `расход`, `kirim` / `chiqim`.
  **Если type отсутствует, положительная сумма считается доходом, отрицательная —
  расходом.** Для файлов с положительными расходами обязательно добавь `type`.
- Даты: `YYYY-MM-DD` или `DD.MM.YYYY`. Сохраняется дата из файла, а не день импорта.
- Суммы: `1234.56`, `1 234,56`; максимум два десятичных знака. Десятичная запятая
  требует разделителя `;` или кавычек вокруг значения. Неоднозначные значения
  вроде `1,000` отклоняются.
- Категории из файла сохраняются. Пустые категории определяются локально по
  ключевым словам описания, без отправки данных в AI; неизвестные — `Другое`.
  Проверь категории в предпросмотре; при необходимости исправь CSV и отправь заново.
- Поддерживаются UTF-8 (включая BOM), Windows-1251 и разделители `,`, `;`, табуляция.
  Лимит: 1 МБ и 2000 операций в файле. При любой ошибке ни одна строка не импортируется.
- Принимается только основная валюта пользователя (по умолчанию UZS), поскольку
  текущие отчёты не поддерживают конвертацию валют. Остальные суммы нужно заранее
  конвертировать и явно указать основную валюту.
- Повторная загрузка **точно того же файла** тем же пользователем не создаёт копии.
  Пересекающиеся операции в разных файлах не выявляются: загружай непересекающиеся
  периоды. `/reset` удаляет транзакции и сохранённые CSV-импорты пользователя.

При запуске бота `init_db()` создаёт новую таблицу `csv_imports`; существующие
таблицы изменять не требуется. Для создания таблицы нужны соответствующие права БД.

Проверка импорта локально (Python 3.12):

```bash
pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

## Установка и запуск

### 1. Клонируй репозиторий

```bash
git clone <repo-url>
cd cash_control
```

### 2. Создай `.env` файл

```bash
cp .env.example .env
```

Заполни переменные в `.env`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
GROQ_API_KEY=твой_ключ_с_console.groq.com
DATABASE_URL=postgresql+asyncpg://cashcontrol:пароль@localhost:5432/cashcontrol
DEFAULT_CURRENCY=UZS
```

### 3. Запусти базу данных

```bash
# Через Docker (только PostgreSQL)
docker compose -f docker-compose.local.yml up -d

# Или через Homebrew (macOS)
brew install postgresql@16
brew services start postgresql@16
createdb cashcontrol
psql cashcontrol -c "CREATE USER cashcontrol WITH PASSWORD 'пароль';"
psql cashcontrol -c "GRANT ALL PRIVILEGES ON DATABASE cashcontrol TO cashcontrol;"
```

### 4. Установи зависимости

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 5. Запусти бота

```bash
python -m bot.main
```

## Деплой на сервер (DigitalOcean)

```bash
# На сервере (Ubuntu 24.04)
git clone <repo-url> /opt/mone
cd /opt/mone
cp .env.example .env
nano .env  # Вставь токены

# Запуск всего через Docker
docker compose up -d
```

Всё — бот работает в фоне 24/7.

## Структура проекта

```
cash_control/
├── bot/
│   ├── handlers/        # Обработчики сообщений и команд
│   │   ├── commands.py  # /start, /today, /week
│   │   ├── voice.py     # Голосовые сообщения
│   │   ├── text.py      # Текстовые сообщения
│   │   └── callbacks.py # Кнопки подтверждения
│   ├── services/        # AI-сервисы
│   │   ├── speech.py    # Распознавание речи (Groq Whisper)
│   │   ├── ai_parser.py # Парсинг трат из текста (LLM)
│   │   └── reports.py   # Форматирование отчётов
│   ├── models/          # Модели базы данных
│   ├── database/        # Подключение к БД и репозитории
│   ├── config.py        # Конфигурация из .env
│   └── main.py          # Точка входа
├── docker-compose.yml        # Продакшн (бот + БД)
├── docker-compose.local.yml  # Разработка (только БД)
├── Dockerfile
├── requirements.txt
└── .env.example
```
